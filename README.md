# Planimulation

An exploratory simulation of procedural Earth-like worlds and the histories that emerge within them.

A reproducible world connects geography, climate, water, ecology, and resources. Populations adapt to their environment; production, connections, and decisions shape settlements, states, and history. Civilizations then change the environment that supports them.

The first standalone deliverable is a configurable visual planet generator with a map and explainable terrain. The next is a living natural environment with seasons, water, and vegetation. Human populations follow once that foundation has been checked.

## Status

These documents record the concept discussion of September 19, 2026. The application and simulation core have not been implemented; there are no runnable application commands yet.

The documents distinguish agreed product principles from proposed technical choices. The spherical mesh, algorithms, and stack are working proposals to validate with a small prototype.

The immediate goal: enter a seed and parameters, generate terrain and oceans, switch geological layers, inspect a region's elevation, and save and reproduce the generation recipe.

Development, documentation, code comments, and project records use English. Conversation with the project owner uses Russian.
